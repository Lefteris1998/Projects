# sources

Assets copied from other projects in this folder, so this game doesn't depend on them.

| File | From | Used for |
|---|---|---|
| `main-screen.mp3` | `../fruit-butcher/ost/Main screen.mp3` | loops on the title screen and in the shop |
| `music1-4.mp3` | `../fruit-butcher/ost/` | one per night, taking turns (night 1 → music1, night 5 → music1 again) |
| `Success2-3.mp3` | `../fruit-butcher/ost/` | a random one plays when you survive a night (Success1 was dropped: too long) |
| `Defeat1-3.mp3` | `../fruit-butcher/ost/` | a random one plays when you get buried |

Same licence note as Fruit Butcher: local testing only, not licensed for publishing.
Fonts (Creepster, Rubik) are the same Google Fonts Fruit Butcher uses, loaded from Google, not copied.
