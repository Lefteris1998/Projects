How Angle Studio works

  1. Add an image: drop it on the window, click ＋, or copy it into the images folder.
  2. A small AI model (Depth Anything V2) runs in your browser and guesses how far each pixel is. The first run downloads it (~25 MB) and caches it. Results are saved in images/_depth, so each image is only processed once.
  3. The depth map is turned into a 3D relief you can orbit. Pseudo-3D looks right up to about ±45°. A single image has no information about the back.
  4. Lights: add Point / Spot / Sun lights, click a bulb in the viewport and drag the arrows to move it, or use “Place at camera”.
  5. For full 360°, generate a .glb with an image-to-3D tool (TripoSR, Hunyuan3D, Meshy, Tripo…) and drop it in. The same lights and clay mode work on it.

Shortcuts

Delete remove selected light · C selected light → camera position · Esc deselect · S screenshot · 1–5 camera angles

Start it with start.bat

Browsers block this app when it's opened directly as a file. Double-click start.bat in the angle-studio folder. It starts a tiny local server and opens the app at http://localhost:5178.
